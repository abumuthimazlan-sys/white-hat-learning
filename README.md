# White Hat Learning — Cybersecurity Arcade

A responsive, beginner-to-advanced cybersecurity learning arcade with a polished dark security-lab interface and safe fictional scenarios.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. There are no build steps or dependencies. Google Fonts are optional; the page falls back to system fonts if unavailable.

## What's included

- Six interactive mini-games across phishing awareness, account security, incident response, secure design, threat modeling, and cryptography concepts.
- Beginner, intermediate, and advanced mission filters plus search.
- Multiple-choice challenges with explanations and a completion/XP tracker saved in local browser storage.
- Responsive layout, keyboard-friendly controls, and reduced-motion support.

All challenges use fictional, defensive learning scenarios. No real systems are contacted or tested.
