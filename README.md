# White Hat Learning — Cybersecurity Arcade

A polished dark cyber theme, ethical white-hat learning content, and a full set of mini-games from beginner to advanced levels.

## Features

- Professional hacker-inspired UI with a secure terminal aesthetic
- Safe cybersecurity learning missions across phishing, passwords, incident response, secure design, threat modeling, cryptography, OSINT, forensics, and firewall triage
- Beginner, intermediate, and advanced filtering
- Searchable mission catalog
- XP/progress tracking stored locally in the browser
- Responsive design for desktop and mobile
- Ethical, fictional learning scenarios with no real system testing

## Run locally

Open `index.html` directly in a browser. If you want a local static server, you can run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Mission coverage

- Phishing awareness
- Account security / password habits
- Incident first response
- Secure-by-design principles
- Threat modeling
- Cryptography basics
- Open-source intelligence ethics
- Digital forensics basics
- Firewall triage and network defense

This project is designed for safe white-hat education and responsible cyber learning.
